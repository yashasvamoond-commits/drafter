## 1. इंस्टॉल कैसे करें (Lenovo Yoga Tab / कोई भी Android 7+)

1. टैबलेट के ब्राउज़र में ऊपर दिया **APK लिंक** खोलें → फ़ाइल डाउनलोड होगी (`NyayaLekh-1.0.0.apk`).
2. नोटिफ़िकेशन/डाउनलोड्स से APK पर टैप करें।
3. Android पूछेगा — **“अज्ञात ऐप्स / Install unknown apps”** में अपने ब्राउज़र (Chrome/Files) को अनुमति दें → *Install* दबाएँ।
4. Play Protect चेतावनी दिखे तो **“Install anyway / फिर भी इंस्टॉल करें”** चुनें (self-signed APK के लिए सामान्य है)।
5. ऐप खोलें। पहला पृष्ठ कुछ सेकंड में खुलेगा (शब्दकोश लोड होता है)।
6. **सुझाव:** ऐप को होम स्क्रीन पर पिन करें और पोर्ट्रेट + लैंडस्केप दोनों में खोलकर देखें — लेआउट दोनों में काम करता है।

बाद के बिल्ड (नई सुविधाएँ) उसी रिलीज़ लिंक पर मिलते रहेंगे (`apk-latest`).

## 2. क्या-क्या है इसमें (फ़ीचर सूची)

### 2.1 हिन्दी पहले (Devanagari-first)
- **तीन स्पष्ट देवनागरी फ़ॉन्ट** ऐप में ही embedded — *Noto Serif Devanagari* (न्यायालयीन), *Noto Sans Devanagari* (स्क्रीन हेतु सर्वाधिक स्पष्ट), *Tiro Devanagari Hindi* (पारंपरिक). मात्राएँ/संयुक्ताक्षर पूर्ण रूप से रेंडर होते हैं (हर ग्लिफ़ ऐप के अंदर, इंटरनेट की ज़रूरत नहीं)।
- अक्षर आकार 9–32 pt, पंक्ति अंतर, संरेखण (बाएँ/केंद्र/दाएँ/justify), इंडेंट, शीर्षक शैलियाँ।
- A4 / Legal / Letter / A5 पृष्ठ, मिमी में मार्जिन, पृष्ठ क्रमांक, वास्तविक पेजिनेशन (टाइप करते ही नए पृष्ठ बनते हैं), प्रिंट-तैयार लेआउट।
- **पोर्ट्रेट + लैंडस्केप** दोनों हेतु responsive UI; टैबलेट पर रेल/रिबन/साइड पैनल।

### 2.2 सम्पादन (Word जैसा, पर हल्का)
- बोल्ड/इटैलिक/रेखांकन/स्ट्राइक/सुपर-सबस्क्रिप्ट, हाइलाइट, क्लियर फ़ॉर्मैट।
- बिंदु व क्रमांक सूची, इंडेंट/आउटडेंट, पेज ब्रेक।
- अंडू/रीडू (80 स्तर), स्वतः-सहेजन (IndexedDB + localStorage fallback), दस्तावेज़ सूची (खोलें/नाम बदलें/प्रतिलिपि/हटाएँ)।
- खोजें (Ctrl+F) अगला/पिछला के साथ, शब्द/अक्षर गणना, ज़ूम।

### 2.3 आयात — WPS Office व अन्य फ़ाइलें
- **.docx** (WPS Office / MS Word / Google Docs से निर्यात), **.odt**, **.rtf**, **.txt**, **.html** — बोल्ड/इटैलिक/अंडरलाइन/संरेखण/शीर्षक शैलियाँ सुरक्षित रहती हैं।
- टेक्स्ट-आधारित **.pdf** से पाठ निकालना (स्कैन की गई PDF हेतु OCR नहीं — ऐप स्पष्ट संदेश देता है)।
- **“Open with NyayaLekh”**: WPS Office/Files से सीधे ऐप में फ़ाइल भेजें।
- आयातित पाठ में कृतिदेव/लीगेसी फ़ॉन्ट पहचाना जाए तो **स्वतः यूनिकोड में बदलने का विकल्प**।

### 2.4 निर्यात / प्रिंट
- **.docx** (Word/WPS में खुलने योग्य, Nirmala UI/देवनागरी फ़ॉन्ट, मार्जिन व पेज साइज़ सहित), **PDF** (Android प्रिंट → “Save as PDF”), **.html**, **.txt**, **.rtf**।
- फ़ाइलें टैबलेट के **Documents/NyayaLekh** में सहेजी जाती हैं (MediaStore के माध्यम से, ताकि WPS Office तुरंत देख सके)।

### 2.5 राजस्थान न्यायालय प्रारूप (टेम्पलेट)
न्यायालय सेटिंग: **JM, ACJM, CJM, ADJ, DSJ, CJM (ग्रामीण), सिविल जज, पारिवारिक न्यायालय, MACT, किराया नियंत्रण, लोक अदालत, राजस्थान उच्च न्यायालय** — न्यायालय का नाम, स्थान, न्यायाधीश, प्रकरण संख्या, पक्षकार, धाराएँ, थाना स्वतः भर जाते हैं (`{{court}}`, `{{caseNo}}`, `{{sections}}` आदि वेरिएबल)।

तैयार प्रारूप (हिन्दी में, संपादन योग्य):
अंतरिम जमानत आवेदन · आरोप पत्र · प्रकृति आख्या (गिरफ्तारी रिपोर्ट) · निर्णय (दोषसिद्धि/दोषमुक्ति) · आदेश–समन/वारंट · अभियुक्त का कथन (धारा 351 BNSS) · मुचलका/जमानतनामा · स्थगन प्रार्थना · नकल आवेदन · **वाद पत्र (दीवानी)** · लिखित कथन · अस्थायी निषेधाज्ञा · प्रथम अपील · पुनरीक्षण याचिका · प्रतिबंध याचिका (केविएट) · शपथ पत्र · विधिक सूचना · किराया नियंत्रण आवेदन · MACT दावा।

### 2.6 शब्दकोश, वर्तनी व भाषा
- **हिन्दी शब्दकोश:** 1,06,082 हिन्दी शब्द + **1,03,174 शब्दों के अर्थ** (CFILT Hindi WordNet, IIT Bombay) + ~230 पेशेवर विधिक शब्द (हिन्दी → English परिभाषा सहित) — सब ऑफ़लाइन।
- **अंग्रेज़ी:** 2,74,801 शब्द; English → हिन्दी विधिक शब्द खोज।
- **वर्तनी जाँचक:** देवनागरी-सचेत (मात्रा/संयुक्ताक्षर सुरक्षित), सुझाव (Damerau–Levenshtein), “शब्दकोश में जोड़ें” (व्यक्तिगत शब्दकोश), लाइव लाल रेखा, और पूरे दस्तावेज़ की जाँच।
- **बोलकर लिखें (Speech to Text):** हिन्दी (hi-IN), English (IN/US) — Android वाक् पहचान; शांत कमरे में सर्वोत्तम।
- **लिप्यंतरण टाइपिंग:** रोमन → देवनागरी (आईट्रांस जैसा) और देवनागरी → रोमन।

### 2.7 कृतिदेव / लीगेसी कन्वर्टर
- **कृतिदेव 010/011/016 → यूनिकोड:** पूर्ण टेबल (225 ग्लिफ़), `ि` की स्थिति, रेफ़ (`Z`), नुक़्ता, क्ष/त्र/ज्ञ/श्र, `ूँ`, विराम-चिह्न — सब संभालता है।
- **यूनिकोड → कृतिदेव** (पुराने टेम्पलेट में चिपकाने हेतु) — द्वि-दिशीय, राउंड-ट्रिप परीक्षित।
- देवलीस 010, चाणक्य, रेमिंग्टन/कुंडली/आगरा (प्रायोगिक — पूर्वावलोकन के बाद लागू करें)।
- **मात्रा-सुधारक:** उलटी `ि`, गलत `ॆ/ॊ`, `अ+मात्रा`, हलंत के बाद स्पेस, अनुस्वार की स्थिति, विराम चिह्न — पूरे दस्तावेज़ पर एक क्लिक में।

### 2.8 विधिक सहायक
- **BNS ↔ IPC** और **BNSS ↔ CrPC** संकेतात्मक तालिकाएँ (खोज सहित)।
- **सीमा अवधि** (Limitation Act) कैलकुलेटर — आरंभ तिथि से अंतिम तिथि।
- **ब्याज कैलकुलेटर** (साधारण/चक्रवृद्धि) — परिणाम सीधे दस्तावेज़ में जोड़ें।
- **तिथि गणना** (स्थगन/नोटिस अवधि हेतु)।

### 2.9 अन्य
- हिन्दी/English UI टॉगल (स्टेटस बार में “हिं/EN”)।
- डार्क/लाइट/सिस्टम थीम, मोबाइल+टैबलेट, हार्डवेयर कीबोर्ड शॉर्टकट।
- डेटा केवल आपके डिवाइस पर; कोई ट्रैकिंग, कोई विज्ञापन, कोई खाता नहीं।

## 4. स्वयं बिल्ड करना

**APK (GitHub Actions — सबसे आसान):** इस ब्रांच पर कोई भी push करें → Actions “Build APK” → artifact `NyayaLekh-APK`, और रिलीज़ `apk-latest` अपडेट हो जाता है।

**लोकल (Android Studio / Gradle 8.x, JDK 17, SDK 34):**
```bash
cd scripts && npm install && node build-data.mjs && cd ..
cd android && gradle :app:assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

**वेब प्रीव्यू (बिना Android):**
```bash
cd scripts && npm install && node build-data.mjs && cd ..
cd app && python3 -m http.server 8000     # → http://localhost:8000
```
